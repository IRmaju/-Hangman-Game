# 🕹️ Hangman Game using Streamlit

Welcome to the **Hangman Game** built with Python and Streamlit!  
Test your guessing skills by uncovering the secret word, one letter at a time!

---

## 🌟 Features

- 🎯 Random word selection from a custom list  
- ✅ Real-time feedback on correct/incorrect guesses  
- ❤️ 6 Lives to guess the word before you lose  
- 🔁 "Play Again" button to restart the game  
- 📱 Simple and interactive UI using Streamlit  

---

## 🎮 How to Play

1. Run the app using Streamlit:
   ```bash
   streamlit run main.py
